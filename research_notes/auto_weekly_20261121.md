## 三、只報告、未修正（需人工判斷）
code-review 對 V6.0.4 跳價檢查的發現。改了會影響「誤擋」和「漏抓」之間的取捨，所以沒有自動修：
1. 容許範圍是 (1±10.5%)^gap，gap 越大範圍越寬。長期停牌後（例如 20 個交易日，上限約 7.4 倍），就算缺少減資參考價，價格跳動也會被放行。建議把 gap 設上限（例如 3～5），或只在股票確實可交易的空白日才累積。這種情況目前沒有測試涵蓋。
2. gap=2 時範圍約 0.80～1.22。冷門股如果除權當天沒有整股成交，又缺少除權參考價，一般配股造成的價格跳動會被當成正常價格。
3. 交易日曆取自 bars 表的 DISTINCT day，不是官方日曆。只要混進一筆異常日期，就會讓 gap 變大、範圍變寬。
4. 每檔股票在本機的第一筆 bar 不會和歷史快照的最後收盤比對（LAG 是 NULL，直接略過）。這個問題在 V6.0.4 之前就有。

### ⭐ 候選獨立複核（不同起始年，run_reference）
做法：自己重寫一個 executor 包裝，不沿用夜間的腳本。每次調倉前把符合條件的續抱股 wc 乘上 m，調倉後再還原。用的是今天的資料（基準週五 48.65%，比夜間的 49.4% 略低，原因是資料更新）。訊號年齡版只對已持有的股票降權，新進場股從第二週才開始降權，和夜間版本略有差異。表中數字為年化 / MDD（%）：

|---|---|---|---|---|---|---|
| 2015 | 48.65 / -30.64 | 49.59 / -32.88 | 52.90 / -32.22 | 48.82 / -32.91 | 51.23 / -30.67 | 53.50 / -30.14 |
| 2017 | 42.71 / -30.64 | 43.41 / -32.88 | 45.56 / -32.21 | 42.59 / -32.91 | 44.91 / -30.67 | 47.16 / -30.15 |
| 2019 | 49.02 / -30.64 | 49.95 / -32.88 | 53.16 / -32.21 | 48.89 / -32.88 | 51.53 / -30.66 | 54.68 / -30.08 |
| 2021 | 40.24 / -30.63 | 41.14 / -32.87 | 43.64 / -32.21 | 40.04 / -32.84 | 43.25 / -30.64 | 45.12 / -29.97 |

Block Bootstrap（2015 年起，比較週對數報酬差，區塊長 26 週，抽 5000 次）：

| | 年化 log 差 | P(>0) | 5%～95% |
|---|---|---|---|
| 週五 H40 m0.25 | +0.63 | 0.93 | -0.11～+1.79 |
| 週五 S45 m0.1 | +2.85 | 0.998 | +1.36～+5.26 |

複核結論：
- **S45 m0.1 獨立重現成功**。10 組「起始年 × 調倉日」的年化全部勝過基準（+1.5～+5.8 點），bootstrap 的 90% 區間不含 0。
- 但**週五 MDD 每一組都變深約 1.6 點**（-30.6 → -32.2），週二則變淺約 2.8 點，和夜間「週五單日路徑分歧」的觀察一致。
- 各起始年的 MDD 數字都一樣，表示最大回撤都發生在同一段（2026 年），起始年不同並不能獨立檢驗風險面。
- H40 m0.25 的增益較小，週五不顯著。
- 結論：**⭐ S45 m0.1 建議人工審核採用**（JS 計畫器需同步，並需用 run() 確認週五 MDD）。目前只完成 run_reference 複核，run() 尚未複核。
