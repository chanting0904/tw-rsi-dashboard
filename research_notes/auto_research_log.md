## 執行環境備註（雲端）
- 預設 `python` 是 3.11 沒有套件，要用 `python3.13`。若用 3.11，安裝時加 `--ignore-installed cryptography`。
- `db_release.py download` 走 gh GraphQL 會 403，改用 curl 下載 `https://github.com/chanting0904/tw-rsi-dashboard/releases/download/local-db/<檔名>`。
- 證交所、櫃買連線被 proxy 擋住，研究腳本要 monkeypatch `v5_engine.security_status.refresh_security_status`，改讀 `output/security_status.json`。
- 研究腳本會 chdir 進 repo，暫存結果檔不要寫在 repo 根目錄。
- 推送 GitHub 回 403（Claude GitHub App 沒有寫入權限），要先修好，否則每次執行都看不到前次紀錄。
